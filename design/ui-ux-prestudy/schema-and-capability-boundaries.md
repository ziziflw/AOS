# 动态Schema表单与实际能力边界

## 字段从哪里来

节点配置表单来自锁定NodeDefinition.configSchema，适配器参数约束来自对应AdapterDefinition能力描述；输入/输出值由端口类型及Schema解释，执行策略单独呈现。不要把三者拼成一个可随意写入的参数对象。模型A、模型B或不同MCP工具可以有不同字段，不能硬编码统一temperature/top_p模板。

画板“最大输出长度”和“温度”对应原catalog的`model.generate`：maxOutputTokens必填integer≥1；temperature可选number，0–2。tool.query只有operation=query的const。画板未实现Schema表单生成器；字段只是按真实定义手工绘制的组件样张。

| Schema/数据 | 拟定控件/规则 |
| --- | --- |
| string | 单行/多行；label独立于placeholder，长度和格式错误就近显示 |
| integer / number | 数值输入，可有步进；保留未完成输入，不把所有值转换字符串 |
| boolean | 开关/复选；默认false不等于字段缺失 |
| enum / const | 有说明的下拉；const只读，不能显示不存在的候选 |
| object | 可折叠字段组，清楚呈现required与additionalProperties规则 |
| array | 有序行/结构化列表；增删移动有键盘替代；保留order |
| nullable | 显式“空值null”选择，与未设置/默认值不同 |
| oneOf / anyOf | 有判别字段时切换分支；无可靠控件时只读Schema诊断并阻断运行，不假装完整支持 |
| $ref | 仅已注册/受检定义解析，未知引用给依赖诊断；不随意联网取Schema |
| FileReference | 显示逻辑resourceUri、媒体/大小/摘要；由宿主受限资源选择器解析，不能给任意路径输入通用权限 |
| secretRef | 只显示配置别名/状态，不回显明文；本轮没有凭据管理界面或真实账户 |
| 未知未来字段/节点 | 保留原数据、只读原始视图与缺失诊断，不能静默删除或宣称可执行 |

Schema的title/description可作默认文案，但不能把不可信描述当HTML/脚本执行。文本长/多语言时允许换行，不通过缩小到不可读字体解决。

## 模型/工具切换

1. 当前定义修订保持不可变；切换只发生在新草稿。
2. 比较节点/适配器的精确版本与Schema摘要，给出保留/新增/不兼容字段差异。
3. 兼容字段也要按新约束验证；未知/不可映射值保留在迁移草稿，不能自动丢弃。
4. 重新验证端口连接、环境绑定、能力、权限及预算；确认后再保存新修订。
5. 旧run继续使用旧锁定定义/attempt/taskId，旧批准不能授权变更后的动作。

执行时看到的值与正在编辑的值在Inspector明确区分。连线输入只读显示来源和当前运行的有效输出；没有有效结果时展示“尚无值”，不把配置预览当执行结果。

## UI表现与P0-06证据

| 界面内容 | 已有依据 | 本轮实际完成 / 尚未完成 |
| --- | --- | --- |
| 版本/健康/状态/事件/取消/批准 | P0-06受限宿主IPC已验证 | 本轮只画样张，未绑定这些命令 |
| 内置受检工作流加载/运行 | P0-06固定builtin入口 | 不等同任意编辑图可运行；画板的拓扑不是受检可执行fixture |
| 原Schema字段与类型 | P0-02及P0-03验证器 | 读取真实字段约束并画控件；未做完整动态renderer |
| 审批暂停 | C1 waiting-approval及后端gate | 文案/指纹范围/过期状态设计；按钮全部禁用 |
| 任意暂停/恢复 | P0-06没有通用pause/resume | 不提供可用的万能暂停按钮；suspend不是任意调用断点恢复 |
| Retry/rerun/debug步进/断点 | 原安全重试语义仅限定场景 | 不展示已可用的通用重试、断点或局部执行能力 |
| 面板自由停靠/密度/布局保存 | 本轮设计规范 | 画板只给预设截图，不宣称交互和持久化已实现 |
| 真实模型usage/成本/账户 | 当前实验未验证 | 不编造价格、消费、连接成功或真实模型名 |
| 运行进度 | 只有适配器真实可核实的事实才可信 | 不伪造百分比、剩余时长或动画表示吞吐 |

P0-07前需要定义草稿校验/固定修订/启动接纳/状态投影的稳定接口，不能让画布编辑事件绕过权限变成命令行执行。UI每次请求都必须经可信后端；按钮禁用仅是反馈，不构成授权边界。
