## 实际审查内容

- A/B/C在同一1440×960视口对比；另看A的审批、失败、运行中、核心组件样张。
- A在1366×768与1920×1080检查文本/布局；768×1024、390×844只看降级预览，明确横向画板边界，没有宣称手机编辑体验完成。
- 手工查看真实ComfyUI/Blender/VS Code截图和较早Blueprint工作区，核对编辑主体与属性/诊断层级。Unreal当前官方图片访问失败，使用大学实验室历史真实截图并明确标注。
- 浏览器记录控制台/pageerror、字段/节点库/按钮溢出、画布尺寸、小地图遮挡、审批区按钮数、执行按钮禁用状态。结构检测辅助人工审查，不代替视觉判断。

## 发现并修正

| 问题 | 为什么静态检查不足 | 修正与证据 |
| --- | --- | --- |
| 小地图挡住输出节点 | 文本未溢出、控制台无错，但遮住有效内容 | 移到不占节点的上方角落；最终桌面截图无节点相交 |
| 审批按钮缺失 | HTML结束标签错误，浏览器容错，CSS/console仍正常 | 补齐正确按钮标签，明确两个独立动作；最终DOM按钮数=2 |
| C折叠库后画布列归零 | CSS grid自动放置重排，Inspector占了中间 | 固定editor/Inspector列位置；实际重新截图核查中央画布 |
| 1366低窗口图中文字过小 | 自动适应整个SVG高度把字压得过小 | 收浅调试区并保持图的最小视口尺度；不承诺低窗口自动显示全图 |
| 输入边界不够明确 | 正文色对比不代表控件可辨 | 分离结构线与control-border语义色，不靠仅变亮正文解决 |

[首轮截图](./evidence/first-render)保留可见缺陷，不隐藏它们。最终画板没有小地图覆盖节点、审批缺按钮、C空画布或所查字段横溢出；不等同完整交互/无障碍验收。

## 尚未验证

没有用户可用性访谈/任务计时；没有面板真实拖动、键盘图导航、触屏、读屏、高DPI实体设备、全Schema生成、图性能或后端事件压力测试。组件焦点/无效字段/版本漂移等是静态视觉状态，不声称交互可用。

画板中的拓扑、时间/事件/operation片段都为合成设计示例，没有付费模型/真实账号，也不是通过Schema后可直接执行的fixture。所有运行/批准按钮禁用，原始日志不占主视觉。当前P0-06功能依据见[后端边界](./schema-and-capability-boundaries.md)；本轮没有改动或重跑其实现，因为没有代码受影响。

最终交付审计：14920份受保护基线文件仅根README导航变更，无缺失或未预期变更；原P0-06引擎/IPC/适配器不变。技能原文/元数据与固定审查提交字节一致，原生加载无错误；可选技能未安装。21组语义文字/控件边界配色满足所列4.5:1或3:1目标，尚不构成完整无障碍合规证明。
