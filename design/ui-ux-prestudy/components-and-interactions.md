# 核心组件与交互规范

所有下述交互为设计规范；本轮只有静态样张与导航链接，没有可交互画布或后端操作。参见[组件截图](./screenshots/components.png)。

## 节点、端口与连接

节点由标题、类型摘要、必要参数/输入摘要、端口、独立运行状态条组成。默认宽180–240，长内容在Inspector展开；可折叠只保留标题/端口/状态。节点显示名称可以友好，但Inspector须能查看完整typeId/version，不能用标题替代版本身份。

选择用2px外轮廓；运行状态用状态条、图标和文字，二者可叠加。失败节点被选中时保留失败标记，蓝色轮廓不能把红色错误“覆盖成成功”。悬停只加强边界，不改变节点尺寸。

输入在左、输出在右，提供类型名、基数与是否必需；颜色仅辅助。端口视觉8–10px，命中12–16px，连接线命中10px。多输入明确order，不按屏幕位置决定运行输入顺序。Text、JSON、文件引用、错误通道不混用；unknown类型不允许偷偷转换字符串。

拖出连线→高亮候选端口→悬停给出兼容/不兼容原因→松手才提交定义命令；非法连接不创建。Esc取消。输入已有单连接时，必须明确确认替换；批量/撤销只改定义。键盘提供“从当前输出连接到…”菜单，不要求精细鼠标拖拽。

连接正常1.5px、悬停2px、选中2.5px；未激活分支虚线+“未激活”，错误连线显示端点问题。不要让虚线同时无说明地表达数据未准备、条件跳过和通信未知。

## 画布操作

| 操作 | 鼠标/触控板 | 键盘与规则 |
| --- | --- | --- |
| 平移 | 中键拖动，或Space+左拖 | H切换手型；不抢表单输入的Space |
| 缩放 | Ctrl+滚轮围绕指针；触控板捏合 | + / −；百分比可输入；25–200%建议范围 |
| 适应全图 | 工具栏“适应画布” | Home；不能在节点状态变化时自动抢视口 |
| 适应选择 | 当前选择右键菜单 | Shift+Home |
| 选择 | 单击；Shift增减；空白框选 | Tab沿图顺序；方向键邻接选择；Esc清除临时操作 |
| 新增节点 | Tab搜索或双击空白搜索 | 搜索支持上下键/Enter/Esc；类型/依赖可预览 |
| 移动 | 拖动节点标题/空白体；8px可选吸附 | G后方向键；Esc恢复原位置 |
| 批量 | 框选后移动/对齐/分布/复制/删除 | Ctrl+A仅焦点在画布时选择图；Ctrl+D复制定义 |

缩放≥80%显示常用摘要；50–80%仅标题、端口和状态；<50%保留轮廓、标题/状态符号，点击后Inspector提供完整内容。低缩放不渲染一堆6px参数。运行中不自动把镜头跳到每个新事件；用户显式开启“跟随当前节点”才跟随，手动平移即退出。

## 多选与参数

Inspector显示“已选N节点”；共同字段可编辑，不同值显示“多个值”。不支持共同Schema的字段只读/分组展示，不能清空差异值。批量删除列出节点/连线数量，允许撤销；复制不复制运行实例、attempt、审批grant或外部taskId。

对齐/分布属于布局，不触发运行。运行中修改参数生成新草稿，当前run固定修订不变。P0-07是否开放运行中编辑需明确控制，不能原地覆盖在途节点配置。

## 运行状态与行动

| C1状态/phase | 视觉文案 | 可提示的下一步 / 禁止误导 |
| --- | --- | --- |
| queued / waiting-dependencies | 等待依赖 — | 展开上游；不是失败 |
| queued / ready | 已就绪 ○ | 等待调度；不能假造开始时间 |
| running | 正在执行 ◌ | 有确切usage/进度才显示；否则不确定进度，默认不动画连线 |
| succeeded | 执行成功 ✓ | 仅展示有效输出 |
| failed | 执行失败 × | 一句原因→定位字段/节点→详情；重试只在后端允许时出现 |
| skipped | 条件跳过 ↷ | 解释未激活分支；不能显示失败或继续永久等待 |
| waiting-approval | 等待审批 ◇ | 展示动作内容/影响/范围/身份/期限；尚未派发 |
| cancel-requested | 取消中 ◼ | 保留响应中状态；发送取消不等于本机/远端已停止 |
| cancelled | 已取消 ■ | 依据C1确认；不接受迟到输出推进下游 |
| unknown | 结果未知 ? | 显示已知operation/task身份，核实原任务；禁止默认“一键重试” |
| waiting-agent-*等phase | 等待外部任务/重新连接 | 展示phase和原taskId；不新增另一套业务终态 |

“暂停”在AOS本轮主要是**等待审批**或已存在的等待phase；P0-06没有通用任意节点pause/resume命令。故不放一个看似可用的万能暂停按钮。宿主suspend保存/关闭不是任意模型调用可恢复断点，取消也不是暂停。

审批区不使用默认勾选的“全部允许”。批准绑定本次动作摘要，清楚区分拒绝与关闭面板；显示内容变化/过期/运行取消后失效。重复点击由后端幂等保护，UI只提供提交中反馈；不能禁用按钮就宣称已实现安全门禁。

## 顶部与底部

顶部固定“保存/校验/环境/运行/取消”，不随画布漂移；执行器断连显示连接问题，不伪造所有节点失败。等待审批在画布状态栏、节点条和Inspector均可发现，显示同一个请求而非三个批准源。

底部默认概览和问题。事件按runId/seq排序并去重，断连明确标记数据缺口和“正在核实”；按需补齐而非用日志最后一行猜终态。点问题定位节点/字段，支持“仅当前节点”。原始日志单独tab、默认不抢焦点；不能把控制台常驻大半屏当专业工具。

## 快捷键与无障碍

Ctrl+S保存、Ctrl+Z/Ctrl+Shift+Z撤销重做、Ctrl+Shift+P命令面板、Ctrl+B左库、Ctrl+Alt+B检查器、Ctrl+J底部、F2重命名、Delete删除选择。Ctrl+Enter运行、Shift+F5请求取消是候选，必须经过焦点范围/确认与后端权限，不能在表单多行输入时误触；P0-07前做Windows冲突检查。

组件焦点2px且可见；tooltip不能作为唯一标签；菜单支持键盘、Esc和返回焦点。面板拖动有菜单替代。颜色之外还用图标/文案；默认无装饰动画，减少动态效果时仍保留重要状态文本。不宣称完整WCAG验收或已完成读屏/高DPI/色觉实测。
