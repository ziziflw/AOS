## 可信边界

不可信内容包括网页、文件、工具描述/结果、Agent消息、导入工作流、模型输出和插件代码。[OWASP](../sources.md#s33)说明间接注入风险；[MCP安全建议](../sources.md#s29)覆盖SSRF、会话问题及本地服务风险。将外部文字放入Prompt时贴标签有帮助，但不能构成操作系统授权。

| 风险 | 程序强制机制候选 | 仅Prompt措施的局限 | 验证 |
| --- | --- | --- | --- |
| 模型被诱导调用危险工具 | 每次派发由策略网关检查操作、路径、目标、参数与授权 | “请勿访问”可被模型忽略 | E06 |
| API Key泄漏 | OS凭据存储、短时注入、前端只见引用、日志脱敏 | “不要输出密钥”不阻止插件直接读环境 | E06/E07 |
| 越界文件访问 | 规范化后校验最终目标、处理链接/重解析点、执行端约束 | 路径字符串白名单可能被绕过 | E06 |
| 网络越界/SSRF | 解析后检查地址、重定向逐跳检查、执行端网络限制 | 域名提示词不防DNS变化或本机程序自行联网 | E06 |
| CLI注入/子进程滥用 | 固定程序和参数数组、资源/输出限制、进程回收 | 启动参数安全不等于子进程有沙箱 | E03/E07 |
| 工作流或工具描述篡改 | 描述快照、内容摘要、版本绑定、变更使授权失效 | 工具自报readOnly不构成可信权限证明 | E03/E06 |
| 日志敏感信息外流 | 字段脱敏、正文保存开关、保留期限和导出审查 | 事后要求模型忘记不会清除磁盘日志 | E02/E06 |

## Windows密钥与进程

[DPAPI](../sources.md#s34)通常绑定用户/机器；[CredWriteW](../sources.md#s35)使用当前token关联凭据集。候选采用系统凭据存储，工作流保存secretRef。二者都不能被宣传为可对抗同账户下任意恶意代码或已泄露的运行时明文；账户迁移、恢复和语言绑定需实测。

[Job Objects](../sources.md#s36)可管理关联进程及限制资源，可用于清理进程树；它不自动提供文件/网络隔离。[Tauri Capabilities](../sources.md#s38)限制WebView可用IPC权限，其边界不能直接延伸成任意Rust函数或sidecar的沙箱。

真正的非可信插件隔离可能需要低权限身份、AppContainer、容器或其他OS机制；本轮未核验这些方案的可行性，不声称已选定。若只能实现参数约束和进程回收，产品必须标为“受控进程”，不得标为“安全沙箱”。

## 授权与审批候选

单一策略模块拥有规则、grant和审批决定；执行模块只消费决定，适配器只接收受限执行上下文。授权应绑定run/节点/操作/资源/参数摘要、有效期和策略版本；发生变更时重新评估。GUI确认框本身不够，必须由执行入口强制拒绝未授权操作。

审批前冻结拟执行操作；审批后若参数或工具实现变更，旧批准失效；应用重启不能把等待状态当作已批准。高影响工具审批与“模型是否愿意遵守”是两个层次。原始工具结果继续保持不可信，不能自行扩大权限。

后续E06包含拒绝、过期、篡改、重启、注入和绕过执行入口用例；与E07联合检查子进程直接访问的真实限制。实验应使用无害临时目录和本地测试服务。
