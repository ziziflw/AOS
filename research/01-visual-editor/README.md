## 初步交互设想

节点面板展示类型、版本、端口、参数支持状态、最近一次执行摘要。动态参数来自节点定义与模型能力描述；切换模型后保留不兼容旧值供用户检查，禁止静默传入。

保存内容应逻辑区分可执行定义、画布布局、运行记录引用。工作流版本、节点定义版本、供应商API版本分别记录。子工作流需定义输入输出边界和依赖版本，不能只把节点视觉折叠。

局部调试有三种候选操作：使用固定样本执行单节点；重新计算目标及必需祖先；从检查点分叉新运行。三者的成本、外部副作用和输入来源不同，界面应明确呈现。以上均为**初步设想**。
