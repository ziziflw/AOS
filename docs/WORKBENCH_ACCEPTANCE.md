# 工作台 0.1.1 可用性验收

## 初查与修复

先运行了 0.1.0 ZIP 内的真实 Tauri 窗口，完成保存、重载、离线执行及本地连接测试服务调用，再修改发行入口。初查没有复现默认示例的 P0 启动失败。

| 严重性 | 现象或源码定位 | 处理 |
|---|---|---|
| P1 | 缺少新建入口；“重载”依赖用户记住或猜出文档名 | 新建空图、欢迎区、受限工作区文件列表；点击名称打开 |
| P1 | 节点、连接、文档名、示例和导入导出共用节点库底部；窄窗口必须反复滚动 | 活动栏切换工作流、节点库和连接，各自独立滚动；选择状态保留 |
| P1 | 点击添加使用整个窗口中心作为坐标，重复添加会重叠 | 按 Vue Flow 实际视口换算坐标、寻找空位；空间不足时扩展并适应画布 |
| P2 | 节点平铺，仅显示名称和内部类型标识；搜索为空没有反馈 | 从后端目录生成分类、用途、可添加性筛选和空结果提示；本地连接未配置时禁用对应节点 |
| P2 | 连接配置对话框和模型场景都挤在侧栏，快捷保存可能早于输入提交 | 模型服务在连接面板配置，使用节点库添加模型；快捷保存先提交编辑 |
| P3 | 活动栏图标语义不清、实验标识抢占空间 | 采用文字入口，移除密度切换、普通检查器的内部实例标识、重复重载入口和无模型时的估算费用行 |

复用现有 Vue Flow 的几何、端口、键鼠交互和现有可调分隔条。项目已有控件足以实现固定工作区；本轮没有新增停靠、命令搜索或大型 IDE 依赖。用户通过点击添加节点；画布内部的节点拖动继续保留。未知节点兼容处理和详细原始记录仍在。后端只新增受限 list-documents 读取操作，原 C1、模型、MCP、A2A、预算及审批实现继续复用。

## 使用限制

保存名称仅支持指定字符，文档列表最多显示256项。切换工作流前应先保存草稿。该版本使用独立用户目录，旧工作流通过 JSON 导入。已配置本地连接只代表保存过配置，服务是否在线仍由实际调用决定。本轮从零连线使用检查器完成，端口拖线、鼠标拖动分隔条、真实本地模型推理和跨机器安装没有作为本轮专项重新验收。下一步建议让首次接触 AOS 的用户按手册独立走一遍流程，记录首次遇到阻碍的位置。
