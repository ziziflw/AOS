# 工作台故障排查

- **无法打开或窗口空白**：从 START_HERE.md 指定的 0.1.2 目录运行 AOS.exe，完整解压 app 和主程序，检查 Windows x64、WebView2 Runtime 与用户目录写权限。首次复制期间请等待。版本目录已存在时启动器会复用副本。
- **执行器断连、节点库为空**：查看底部连接状态和顶部错误。目录由执行器返回，连接失败会影响节点列表。关闭窗口，确认私有运行文件完整后重新启动。节点库无匹配时清除搜索词和「仅显示可添加节点」筛选。
- **无法添加或看不到节点**：展开节点库，点击可用节点名称，再点「适应画布」。本地模型显示缺连接时先进入「连接」配置。
- **端口无法连接**：从输出连接到输入，核对类型、方向和已有连线。单输入端口需先删除旧边。可改用检查器「作为起点」「连接至此」查看原因。
- **工作流无法运行**：先完成一个文本输出节点的连线，移除孤立节点，检查模型参数或等待审批。在「问题」中定位节点，使用「事件」查看最后确认状态。
- **保存失败**：检查保存名称字符和长度，在「工作流」中选取文件名。确认当前 Windows 用户的数据目录可写，先导出 JSON 备份。同名保存会更新同一文件。
- **本地模型不可用**：确认对应服务在本机运行，地址以 /v1 结尾，重新测试并检查模型列表。空列表需在模型服务中加载模型。连接不通可先用离线示例。
- **MCP 工具失败**：确认 app 已完整解压，查看运行目录中 mcp-* 子目录的 stderr.log，确认输入为工具要求的参数类型。审批示例需先在运行结果区批准。
- **运行结果未知**：重新启动后核对已确认的事件和运行 ID。外部操作结果无法确认时，避免重复发送可能已生效的请求。

用户目录为 %LOCALAPPDATA%\AOS-Demo\v0.1.2\experiments\p0-08。已保存文档在 workspace，宿主和执行器日志在 evidence\session-desktop，节点快照在该目录的 runs 子目录。排查时提供版本、窗口尺寸、复现步骤、错误码和脱敏截图。请遮住提示词、输出和个人路径，保管好工作流备份。

**面板折叠**：点击左侧活动图标重新打开对应侧栏。在底部状态栏点「属性」或「输出」可恢复对应面板。拖动区域之间的边线调整可用空间。
