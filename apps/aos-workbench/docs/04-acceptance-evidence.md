# 首版浏览器验收归档

这份记录针对 2026-11-09 的独立工作台首版。后续设计应另存截图并重新验收。

在 Windows 上启动项目独立 Vite 开发服务器后执行 `node tests/acceptance.cjs`。Playwright 驱动本机 Edge 157.0.4341.42，以独立的临时浏览器会话打开 127.0.0.1:4177。所有草稿和布局写入该会话。

|检查|结果|实测|
|---|---|---|
|演示状态与运行按钮|PASS|运行禁用，说明可读。|
|分类、搜索、添加和属性编辑|PASS|画布从 6 个节点增至 7 个，选中节点可更名。|
|撤销、重做、保存及重载|PASS|重载后能读取编辑过的节点名。|
|实际拖动停靠标签合并、再分屏|PASS|分组数 3 → 2 → 3；检查器从右侧合并至目录，再拖至画布底部。|
|实际拖动分隔线|FAIL|在上述布局中拖动分隔线后，未测到目录宽度发生预期变化。尚未定位是拖动坐标还是控件行为。|
|窗口菜单和命令搜索|PASS|菜单重开、Ctrl+K 搜索、无匹配、Enter 打开和重复聚焦通过。|
|切换预设、保存及重开布局|PASS|两次预设切换生效；保存并重新加载后保留关闭目录的状态。|
|恢复保护和损坏数据|PASS|取消重置保护布局。损坏布局回退至编排预设，保留已保存图。|

三份首屏截图的视口分别为 [1440×900](evidence/desktop.png)、[960×720](evidence/compact.png)、[390×844](evidence/mobile.png)。均无页面级横向溢出，窄屏以标签切换三个工作区面板。浏览器检查期间未记录页面异常或外部页面请求。逐项数据见 [browser.json](evidence/browser.json)，首次失败已保存在 [browser-first.json](evidence/browser-first.json)。

此表只覆盖浏览器。原生窗口的独立测试见 [desktop-test.json](evidence/desktop-test.json)。
